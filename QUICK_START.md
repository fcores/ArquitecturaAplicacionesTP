# 🚀 Inicio Rápido - TicketPardo

## ⚡ Comando único para levantar toda la aplicación

```bash
npm run dev
```

¡Eso es todo! Este comando:
- ✅ Levanta el backend FastAPI en http://localhost:8000
- ✅ Levanta el frontend React en http://localhost:3000
- ✅ Muestra logs con colores diferenciados
- ✅ Recarga automáticamente al hacer cambios
- ✅ Para ambos servidores con Ctrl+C

## 📋 Otros comandos útiles

```bash
# Instalación completa (primera vez)
npm run setup

# Probar la API
npm run test-api

# Solo backend
npm run start-backend

# Solo frontend
npm run start-frontend
```

## 🌐 URLs importantes

- **Aplicación**: http://localhost:3000
- **API**: http://localhost:8000
- **Documentación API**: http://localhost:8000/docs
